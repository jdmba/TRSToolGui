# ============================================================================
#  TRSToolGui — French text (français). A copy of en.txt with the text
#  translated: the keys, their order and the comments are the English file's,
#  so the two can be compared line by line. A key this file does not define
#  falls back to the English in en.txt. Do not rename a key: the code looks
#  text up by it.
#
#  Format: key=text, one per line, the first "=" separates them. A line whose
#  first non-blank character is "#" is a comment. {0} and {1} mark where the
#  program substitutes a value, and a translation may put them in whatever
#  order its grammar needs. \n is a newline, \t a tab, \\ a backslash, and \s
#  a space that has to survive at the start or end of the text. Keys are
#  grouped by where the text appears, the same grouping as en.txt.
# ============================================================================
