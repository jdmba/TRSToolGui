TRSToolGui — Manual
===================

TRSToolGui is a front end for Lawrence Kesteloot's trs80-tool, in the spirit of
Matthew Reed's TRSTools. trs80-tool does all the disk work: listing, extracting, adding and every
edit. At startup the GUI asks the trs80-tool it found what it can do and greys out any menu item
that version can't do. It runs on Windows, from version 1.3 on Linux, and from version 1.4 on the
Mac. This manual describes the Windows program; the sections ON LINUX and ON THE MAC at the end
list what differs there.

TRSToolGui 1.6 needs trs80-tool 5.1.0 or later (https://www.my-trs-80.com/tool/). An older one is
refused at startup with a message saying so. With trs80-tool 5.2.0 or later, Montezuma Micro CP/M
disks (and the other CP/M layouts trs80-tool knows) can be changed too: Add, Delete, Rename and
the two CP/M attributes work on them, and File > New makes them. CP/M keeps no file dates, so
files go on without one. 5.2.0 also opens gzipped images (GAME.DMK.GZ, BIG.HDV.GZ) and draws the
granule map of a hard disk partition.

TRSToolGui is by Ira Goldklang and Claude AI. It is free software under the MIT License
(Help > License).

This manual goes through the menus in order: each menu item, what it does, and the options in the
window it opens.


MAIN WINDOW
-----------
  File list     Columns: Name, Type, Size, Date, Attributes, Kind. Click a column header to sort.
                Damaged files are marked. Invisible and system files use TRSTools' row colours.
                Attributes: I invisible, S system; on LDOS, TRSDOS 6 and LS-DOS 6 disks also
                C created and * modified since the last backup; on CP/M disks R read-only and
                * archive.
  Keys          Enter = preview the file, Delete = delete the selected files,
                Esc = exit (only if "Exit upon ESC" is on in Preferences).
  Drag & drop   Drop Windows files (or a folder: its files) onto the list to add them to the
                open image; drag files from the list out to Explorer to extract them.
  Toolbar       New, Open, Disk properties | Copy, Paste | Add, Extract, View | Sectors | About.
  Status bar    The DOS, the number of files, the free space and whether the image is
                write-protected, read-only (and why), damaged or shows signs of copy protection;
                the trs80-tool version on the right.
  Command line  TRSToolGui.exe [image file]  opens that image at startup.


FILE
----
  New...  (Ctrl+N)
      Creates a new, empty floppy image.
      Disk image type      JV1, JV3 or DMK.
      File system (DOS)    TRSDOS 2.3 (Model I), TRSDOS 1.3 (Model III), LDOS 5.3 (Model I/III),
                           TRSDOS 6.2 (Model 4), LS-DOS 6.3 (Model 4), and with trs80-tool 5.2.0
                           Montezuma Micro CP/M 2.2 (Model 4). A CP/M disk is double density with
                           40 or 80 tracks and 1 or 2 sides, and has no volume name or date. Its
                           system disk is Montezuma CP/M 2.32, 40 tracks, one side.
      LDOS for Model       I, III or 4 (LDOS only).
      System disk          "System (bootable) disk from trs80-tool's bundled DOS", optionally
                           "only the DOS's own files (--minimal)".
      Density              Single or Double.
      Sides                1 or 2.
      Tracks (cylinders)   35, 40, 80 or Other.
      Volume information   Name (8 characters) and Date (YYYY-MM-DD).
      You are then asked where to save the image.

  New hard disk image...
      Creates a new HDV hard disk image.
      Shape                Cylinders (1-1023) and heads (1-8). The defaults, 840 and 6, are what
                           FreHD makes.
      Contents             LS-DOS 6.3 partitions, LDOS 5.3 partitions, or blank (no partitions;
                           add them with View > Partition > Add a partition).
      Number of equal      Otherwise as few as keep each partition at 203 cylinders or fewer.
        partitions
      LDOS boot sector     Model III or Model I (LDOS 5.3 only).
      Disk name            Only when there is one partition; otherwise HARDA, HARDB, ...
      An HDV file has no partition table, so trs80-tool prints the settings that the DOS's
      hard disk driver must be given to find the partitions. They are shown in a window you can
      copy or save.

  Open...  (Ctrl+O)
      Opens a disk or tape image: JV1, JV3, DMK, DSK, HDV (with partitions), SCP, HFE, IMD,
      CAS, WAV. With trs80-tool 5.2.0 any of them may be gzipped (GAME.DMK.GZ): the image is
      read, changed and saved compressed, and every window works on it as on any other.

  Open Recent
      The images you opened most recently. Pick one to open it again.

  Close
      Closes the open image.

  Disk properties...
      The "Virtual disk properties" window.
      Volume information   Volume name, volume date (YYYY-MM-DD), master password
                           ("Set master password:", blank = none), AUTO command.
      Disk information     Location, format, file system, "From the bytes:" (DOS and version
                           read from the FORMAT-written bytes), cylinders, sides/heads, density,
                           capacity, free space (with the granules new files can't use counted
                           apart; blocks on a CP/M disk), damaged, copy protection (how many
                           signs trs80-tool found, and the scheme where a sign names one),
                           imaging artifacts, writable (and why not).
      PDRIVE               NEWDOS/80 disks: the PDRIVE line from trs80-tool, which reads TI, TSR
                           and the I/J/K flags from the disk's own drive table. A disk with no
                           table (a data disk) gets the line worked out from its layout, without
                           TI's letter and TSR; the window says which it is.
      Write protected      The image's own write-protect flag.
      Check...             Opens Disk > Check & repair.
      DMK analysis...      Opens Disk > DMK analysis.
      Details from         The raw information trs80-tool reported.
        trs80-tool

  Save image as... (convert format)
      Writes a copy of the open image in another format: DMK, JV3, JV1, HFE or IMD. The file
      extension you choose picks the format (.dsk is not accepted, it doesn't name a format).

  Exit
      Closes TRSToolGui.


EDIT
----
  Copy  (Ctrl+C)
      Copies the selected files to the Windows clipboard, so you can paste them in Explorer or
      into another image.

  Paste  (Ctrl+V)
      Adds the files on the clipboard to the open image.

  Add files...
      Adds Windows files to the open image. The GUI checks each name against the DOS's rules and
      offers a rename; trs80-tool refuses the whole add if there is no room on the disk, and
      nothing is written. If the disk already has a file with
      that name, the "Confirm File Replace" window shows both files and asks:
        Yes / No             Replace this file, or skip it.
        Do this for all      Use the same answer for the rest of the files.
          remaining files

  Extract...
      Copies files from the image to a Windows folder.
      Files to extract     Selected files, or All files shown.
      Directory            The folder to extract to.
      Lower-case host file names.
      Mark damaged files   Adds [DAMAGED] to the Windows name (--mark-damaged).
      CP/M                 Keep whole 128-byte records instead of ending text at Ctrl-Z
                           (--cpm-records).
      UCSD Pascal          Keep text files exactly as on the disk (--ucsd-pascal-raw).

  Select all  (Ctrl+A)
      Selects every file in the list.

  Invert selection
      Selects the unselected files and unselects the selected ones.

  Preferences...
      trs80-tool location  Where trs80-tool.exe is. If it is blank or the file is
                           missing at startup, the program asks where trs80-tool is.
      Text from TRS-80     For extract, copy and drag out: No conversion, Convert CR to CR/LF,
                           or Convert CR to LF.
      Text to TRS-80       For add, paste and drop: No conversion, or Convert CR/LF to CR
                           (only for files that look like text, whatever their extension).
      Let trs80-tool tokenize BASIC text (.bas) and convert cassette programs (.cas/.3bn) when
                           adding.
      Record the Windows file's date on files added (where the DOS stores dates).
      Unzip files named *.gz when adding them, and store the file inside. Off (the default): a
                           .gz file goes onto the disk as it is, as TRSTools stored it. On: it is
                           unzipped first, and the name, the text test and the conversions are
                           those of the file inside.
      Exit upon ESC.
      Confirm before deleting files.
      Keep trs80-tool running in the background
                           One trs80-tool stays running and answers every disk question, instead
                           of the program being started for each one. Much faster. If it ever
                           stops answering, the GUI goes back to one start per action for the
                           rest of the session. Help > Engine capabilities says which is in use.
      Language             The language of the program's own text: English or French. The
                           choice takes effect the next time the program starts. What stays in
                           English whichever you pick: the disk analysis reports, anything
                           trs80-tool itself prints, this manual and the changelog.
      trs80-tool log file  Passes --log-file on every call. Blank = no log.
      Disassembly options  The default words passed to "disasm" for the file viewer. "Default"
                           puts back the standard set (the same listing TRSTools produced).
      The window also shows where the settings file is: TRSToolGui.cfg, in the same folder as
      TRSToolGui.exe.


VIEW
----
  Invisible files
      Shows or hides invisible files.

  System files
      Shows or hides system files.

  Partition
      On a hard-disk image (HDV): picks the partition to show.
      Add a partition...   Formats an empty LS-DOS 6.3 or LDOS 5.3 data partition in the image's
                           free space. Cylinders (35-203; otherwise the rest of the free block),
                           disk name, and for LDOS the model of the boot sector. trs80-tool then
                           prints the settings the DOS's hard disk driver must be given.
      Delete this          Erases the partition being shown, with its files. The partitions after
        partition...       it get numbers one lower. You are asked to confirm.

  Refresh  (F5)
      Reads the image again.


DISK
----
  Sector map...  (Ctrl+M)
      A grid of every track and sector. Legend: S single density, D double density, C CRC error,
      X deleted-data mark, ? not found, - not on this track. Click a sector to see its header line
      and a hex dump.
      Bad sectors          The missing and CRC-error sectors and the files that use them. A bad
                           sector that the imaging explains (the read began late, or stopped after
                           one revolution, or a converter made up the CRC) says so: reimaging the
                           disk may read it.
      Text report...       The map as text.
      Bad sectors (text)...
      Save report...
      Refresh
      Protection &         trs80-tool's signs of copy protection on this floppy, each with its
        artifacts...       verdict (protected, DOS protected, possible, or not protection) and the
                           trs-80.com scheme numbers it has been seen with, and the imaging
                           artifacts. No signs doesn't prove a disk is unprotected.

  DMK analysis...  (Ctrl+D)
      Read-only analysis of a DMK image by the GUI itself: DOS, model and version from the
      FORMAT-written bytes, signs of copy protection, damage versus imaging artifacts, tail
      tracks, and a table per track. On a NEWDOS/80 disk it also works out the PDRIVE
      settings from the media (density, sides, sectors, the directory and the GAT), so a disk
      without a drive table gets them too, with one line per machine and interface that can
      read it (Model III standard or Apparat; Model I standard, Percom, LNW or Omikron), and
      checks them against what the boot sector and the drive table say.
      Buttons: Copy report, Save report...

  Granule map...
      Every granule of a TRSDOS-family floppy as a grid: one row per lump (a cylinder, on most
      DOSes), one column per granule. With trs80-tool 5.2.0 it also draws the open partition
      of a hard disk. A number is a file (listed at the right, in the same
      colour); · free, B boot, D directory, - another file, x locked out, ! shared by files,
      ? claimed but free, u used but unclaimed, n not on the image, p past the disk's end.
      Click a granule for who claims it and where its sectors are; click a file to jump to it.
      Only these files     TRS-80 name patterns, e.g. *.BAS SYS?.SYS. Press Show or Enter to
                           redraw. Blank = all files.
      trs80-tool's text    The same map as trs80-tool draws it, to copy or save.
        map...
      Refresh

  Check & repair...
      Runs "disk check" when it opens and shows the result.
      Also free granules the GAT marks used but no file claims (--free-unclaimed).
      Also fix program sizes whose transfer record is past the directory size
                           (--fix-program-sizes).
      Also mark used the free granules the image doesn't fully hold, so the DOS won't use them
                           either (--mark-missing-used).
      The check also lists signs of copy protection and imaging artifacts. trs80-tool refuses to
      repair a disk that shows signs of copy protection.
      Re-check             Runs the check again.
      Preview repair       Shows what a repair would change, without changing anything.
        (dry run)
      Repair               Repairs the image. Not allowed while the image is write-protected.

  CP/M layout...
      For CP/M floppies, with trs80-tool 5.2.0. A CP/M disk doesn't say how it is laid out, so
      trs80-tool works it out. When it picks the wrong layout, this window shows trs80-tool's
      list of the layouts it knows; type the name of the right one (for example mm-ds-data) and
      press "Use this layout". The disk is then read and written that way in every window, and in
      the trs80-tool shell, until TRSToolGui closes. The status bar says so. "Let trs80-tool
      decide" goes back. A name the disk can't be read with is refused and nothing changes.

  Format...
      Erases every file on the open image and formats it as an empty data disk. DMK images
      only (gzipped ones included). Use File > Save image as to make a DMK copy first. You are
      asked to confirm.
      The options are the same as File > New (DOS, density, sides, tracks, volume name/date).

  Trim...
      Removes the part of the image the disk doesn't use.
      Drop only the cylinders trs80-tool can prove are past the disk's end (default). It says
                           why it kept the others, and trims nothing when the DOS's records
                           don't prove where the disk ends.
      Keep cylinders 0 to N-1, with N = ...
      Drop side 1, keeping only side 0 (--side 0).
      Force                Drop tracks whose data can't be proven unused, or trim a
                           write-protected image (--force). Tracks with signs of copy protection
                           are never dropped.

  Boot in the emulator...
      Starts trs80-tool's emulator with the open image in drive 0.
      TRS-80 model         Model I, Model III or Model 4 (--model).
      Writable             Let the emulated DOS write to the image (--writable). Otherwise every
                           floppy is write-protected.
      Also mount           More images for the next drives (--mount). Add... / Remove.
      Printer output file  Where printer output goes (--printer, optional).

  Open trs80-tool shell here
      Opens trs80-tool's interactive disk shell on the image in a console window. The GUI is
      locked while the shell is open and reads the image again when it closes.


TOOLS
-----
  Convert file(s)...
      Runs "trs80-tool convert" on Windows files.
      Input file(s)        Add... / Remove. Several inputs are combined into one CAS/WAV file.
      Output file          The extension picks the conversion: .bas .asc .cmd .3bn .cas .wav
                           .dmk .jv1 .jv3 .hfe .imd, and .png for a hi-res screen dump
                           (.hr .hrg .hrx .chr .shr).
      Cassette baud        default, 250, 500 or 1500 (--baud, CAS/WAV only).
      Start address        Hex or auto (--start; ROM/BIN to CMD/3BN).
      Include system files when the input is a disk image (--system).
      CP/M: keep whole 128-byte records (--cpm-records).
      Floppy images: write even if the new format can't hold everything (--force).
      trs80-tool output    What trs80-tool printed.

  Assemble...
      Runs "trs80-tool asm".
      Z80 source file      The .asm file.
      Output file          .cmd, .3bn, .cas or .wav.
      Target               Model I, Model III (default) or Model 4 (--model; defines __MODEL__
                           for the source).
      Cassette baud        default (500), 250, 500 or 1500 (--baud).
      Write a listing file next to the output (--listing OUT.lst).
      trs80-tool output    What trs80-tool printed.
      When an image is open, you are offered to add the result to it.

  Hex dump of a file...
      Pick any Windows file; its hex dump is shown in a report window.

  Disassemble a file...
      Pick a TRS-80 program (.cmd .sys .3bn .rom .bin .cas); the disassembly is shown in a report
      window, using the disassembly options from Preferences.

  Run the emulator without a disk...
      Starts the emulator with no disk mounted: Model I (Level II BASIC), Model III or Model 4.


HELP
----
  Manual...  (F1)
      This manual.

  Changelog...
      What changed in each release.

  License...
      The MIT License TRSToolGui is released under, and notes on trs80-tool and TRSTools.

  Engine capabilities...
      The trs80-tool version that was found, where it is, how it is being called (background
      server or one start per action), the commands and options it has, and the DOSes and image
      formats it handles.
      Re-check engine      Checks trs80-tool again (e.g. after you install a new version).
      Copy to clipboard

  trs80-tool manual (web)
      Opens https://www.my-trs-80.com/tool/ in your browser.

  Report a problem (web)
      Opens the TRSToolGui issues page in your browser. REPORTING A PROBLEM below says what
      is worth putting in a report.

  About TRSToolGui...
      The version, release date and build of TRSToolGui, and which trs80-tool it uses.


FILE LIST RIGHT-CLICK MENU
--------------------------
  Preview              Opens the file viewer (also Enter or double-click).
  Extract...           As Edit > Extract.
  Delete               Deletes the selected files (asks first if Preferences says so).
  Rename...            Gives the file a new TRS-80 name.
  Convert to...        Extracts the file and runs Tools > Convert file(s) on it. You can then add
                       the result back to the image.
  Properties...        The "File Properties" window:
                         Filename, Date (YYYY-MM-DD, or "No date"), Size, Kind, Damage, SHA-256,
                         Protection (the DOS's own levels), Attributes (Invisible, System; on
                         the LDOS line also whether the file is Created and MOD), the passwords
                         it has now (none, PASSWORD, or set),
                         Set update password / Set access password (blank = remove; the access
                         password can't be set where the disk keeps a time stamp there).
                       On a CP/M disk (trs80-tool 5.2.0): Filename, Size, Kind, and the two
                         CP/M attributes, Read-only (R/O) and System (SYS, which keeps the file
                         out of DIR). CP/M 2.2 has no dates, passwords or protection levels.


FILE VIEWER
-----------
  Opened by Preview, Enter, double-click or the View toolbar button. It picks the view itself;
  the type list overrides it: Graphics, EDTASM, BASIC, Disassembly, Text or Hexadecimal.
  Graphics             Hi-res screen dumps (HR, HRG, HRX, CHR, SHR), drawn by trs80-tool.
                       Save as writes a PNG.
  Font                 Monospaced or Proportional.
  Save as...           Saves the current view.
  Done                 Closes the viewer.
  Options...           Depends on the view:
    Disassembly        Listing (--listing), listing without the bytes (--no-binary), upper-case
                       (--upper), no labels for jump targets (--no-labels), no labels for known
                       ROM locations (--no-known), everything as instructions (--full), ASCII
                       comment per instruction (--data-comment), hex number format (--hex-format:
                       default, c 0x12, dollar $12, h 12h), load address (--org), extra entry
                       points (--entry). "Make these the default" saves them to Preferences.
    BASIC              The disk's DOS decides (default), Model I/III BASIC tokens (--basic 3), or
                       Model 4 BASIC tokens (--basic 4).
  For assembler source the viewer also names the layout, the line count and which assembler
  most likely wrote it.


REPORTING A PROBLEM
-------------------

  Every problem report for TRSToolGui is an issue at https://github.com/jdmba/TRSToolGui/issues,
  and Help > Report a problem (web) opens that page. Keeping them in one list means none gets
  lost, and each one keeps its own thread until it is answered or fixed.

  What is worth putting in a report:
    - the two version lines from Help > About: the release and the build it was made from;
    - the trs80-tool version, which Help > Engine capabilities names;
    - Windows, Linux or a Mac, and which version of it;
    - what you did, what you expected, and what happened instead;
    - the exact words of any message, copied rather than described;
    - the disk image itself, if one particular disk causes it and you are able to share it.

  A word that reads wrongly in another language is worth reporting too. The French text is a
  first translation and no native speaker who knows TRS-80 disks has been through it yet, so a
  term that is wrong for floppies is useful to hear about.


ON LINUX

  TRSToolGui for Linux (x64) is the same program with its windows built on Eto.Forms, which
  uses GTK 3. Every menu, dialog and window above is there. What differs:

  Starting it          Unzip TRSToolGui-v1.6-linux-x64.zip, make the file runnable once with
                       "chmod +x TRSToolGui", and start it:  ./TRSToolGui [image file]
                       It needs GTK 3, which desktop Linux has, and nothing else: .NET is inside
                       the file.
  trs80-tool           Use the Linux trs80-tool (https://www.my-trs-80.com/tool/). TRSToolGui
                       looks where Preferences says, then beside itself, then on the PATH, and
                       asks only when none of those has it.
  Settings             ~/.config/TRSToolGui/TRSToolGui.cfg (or under $XDG_CONFIG_HOME).
  Text from TRS-80     The default is Convert CR to LF. Reports are saved with LF line ends.
  Shell and emulator   Disk > Open trs80-tool shell, Boot in the emulator and Tools > Run the
                       emulator open in a terminal window. The first one found of
                       x-terminal-emulator, gnome-terminal, konsole, xfce4-terminal,
                       mate-terminal, lxterminal, alacritty, kitty and xterm is used;
                       Preferences has a box to name another (for example "xterm -e"). The file
                       list is read again when that window closes.
  Paste                Is offered whenever the disk can be written; it says so in the status
                       line when the clipboard holds no files. Copy puts the files on the
                       clipboard for the file manager to paste.
  Drag & drop          Dropping files or a folder onto the list adds them. Dragging files out of
                       the list is not in the Linux program; use Copy or Extract.
  Extract              When a file exists in the target folder, the question has a "Do this for
                       all remaining files" box in place of the Shift key.
  Sector map and       Click a cell to see that sector or granule; the row is highlighted.
  granule map          There are no tooltips on cells or on the file list.
  Dialogs              OK and Cancel are in the title bar, as GTK programs have them.
  Exit                 File > Exit, or Ctrl+Q.


ON THE MAC

  TRSToolGui for the Mac is the Linux program's source built for macOS: the same windows on
  Eto.Forms, which uses the Mac's own controls there. It was built on Windows, and when this was
  written it had not yet been run on a Mac, so expect rough edges and please report them. What
  differs from the rest of this manual:

  Which download       TRSToolGui-v1.6-macos-arm64.zip for a Mac with Apple Silicon (M1 and later),
                       TRSToolGui-v1.6-macos-x64.zip for a Mac with an Intel processor. It needs
                       macOS 14 or later and nothing else: .NET is inside the app.
  Installing it        Double-click the zip to unpack it, then drag TRSToolGui.app to Applications
                       or to any folder you like. Move it before the first start: macOS runs a
                       downloaded app that was never moved from a temporary copy of its folder,
                       and from there TRSToolGui can't see a trs80-tool put beside it.
  The first start      The app is not signed with an Apple developer certificate, so macOS refuses
                       it once. Double-click it, close the message, then open System Settings >
                       Privacy & Security, scroll down to the line about TRSToolGui and click
                       Open Anyway. If macOS says the app is damaged, or that line isn't there,
                       clear the download mark in Terminal and start it again:
                         xattr -dr com.apple.quarantine /Applications/TRSToolGui.app
  trs80-tool           Use the Mac trs80-tool for your processor (https://www.my-trs-80.com/tool/).
                       Its download is a zip, and the program comes out of it ready to run,
                       but macOS has to be told once to allow it. In Terminal, in the folder
                       the file is in:
                         xattr -d com.apple.quarantine trs80-tool
                       TRSToolGui looks where Preferences says, then in the folder TRSToolGui.app
                       is in, then on the PATH, then in /opt/homebrew/bin, /usr/local/bin, ~/bin
                       and ~/.local/bin, and asks only when none of those has it.
  Menus                About, Preferences (Cmd+,) and Quit (Cmd+Q) are in the TRSToolGui menu, and
                       there is a Window menu. Shortcuts use Cmd where this manual says Ctrl.
                       File > Close image closes the disk image; File > Close (Cmd+W) closes the
                       window.
  Edit menu            Cut, Copy, Paste, Delete and Select All are the Mac's own items. In a text
                       box they work on the text. When the file list has the focus, Copy, Paste
                       and Delete do what this manual says they do to the list, and Select All
                       selects every file. The Copy and Paste buttons of the toolbar always mean
                       the list.
  Keys                 The delete key deletes the selected files.
  Closing the window   Leaves TRSToolGui running, as Mac programs do. Click its icon in the Dock to
                       get the window back. Quit ends it.
  Command line         /Applications/TRSToolGui.app/Contents/MacOS/TRSToolGui [image file]
  Settings             ~/Library/Application Support/TRSToolGui/TRSToolGui.cfg
  Text from TRS-80     The default is Convert CR to LF. Reports are saved with LF line ends.
  Shell and emulator   Disk > Open trs80-tool shell, Boot in the emulator and Tools > Run the
                       emulator open in a Terminal window. Preferences has a box to name another
                       terminal program (for example "open -a iTerm"). The file list is read
                       again when the shell or the emulator ends; the Terminal window stays open
                       until you close it.
  Paste                Is offered whenever the disk can be written; it says so in the status
                       line when the clipboard holds no files. Copy puts the files on the
                       clipboard for Finder to paste.
  Drag & drop          Dropping files or a folder from Finder onto the list adds them. Dragging
                       files out of the list is not in the Mac program; use Copy or Extract.
  Extract              When a file exists in the target folder, the question has a "Do this for
                       all remaining files" box in place of the Shift key.
  Sector map and       Click a cell to see that sector or granule; the row is highlighted.
  granule map          There are no tooltips on cells or on the file list.
